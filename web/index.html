The Problem

解决的问题

  1. 1200 页财报里找"2022 年资本开支"，要翻目录、跳页、来回比对。
  2. 2找到了答案却无法确认出处，不敢直接引用。
  3. 3每次都要重新提问，助手并不记得你关心哪些指标。

答案 + 精确页码 + 记忆延续

Core Features

核心功能

  • Full-page parsing

    全页解析

    pypdf 逐页抽取，503 页 / 0 跳过。

  • Page-level retrieval

    页级检索

    每页一条 pdf-page 记忆，检索命中即定位到页。

  • Page citations

    页码引用

    答案来自原文片段，引用可回查（示例：PEPSICO_2022_10K p71）。

  • Memory reuse

    记忆复用

    记住用户偏好，下次提问自动拼入检索词。

本地运行 Run locally

依赖 Python 3.11+ 与一个可访问的 PowerContext 实例，三步起服务：

pip install -e . cp .env.example .env bash scripts/run.sh
